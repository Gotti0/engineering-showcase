# 합성 입력으로 실행하는 예제

실제 프로젝트 코드를 복사하지 않고 개념 설명용으로 새로 작성했습니다.
API·임베딩 모델·주문 전송은 사용하지 않습니다. Python 3.10 이상, 외부 의존성 없음.

```shell
python examples/demo.py
python -m unittest discover -s examples -v
```

실행 결과: 격리 첫 실행 1행·재실행 0행, 검색 faq-a, 예약 성공 1회.
검증 대상: OHLC 관계식·비유한 값, 격리 재실행, 검색·벡터 예외, 동시 예약과 상태 전이.
테스트는 6개입니다. 원본 시스템의 테스트 82건·함수 정의 1,000개와 관계없는 별도 범위입니다.
