# 에이전트 개발 워크플로우

## 문제와 역할

여러 코딩 에이전트의 작업을 맡길 때 역할, 작업 공간, 변경 근거를 분리하는 개발 체계를 구성했습니다. 개인 및 공동 개발에 활용했으며 실제 운영 설명은 작성자의 확인에 근거합니다.

## 구현 구조

Paperclip에서 CEO 직속 QA와 개발 라인을 구성해 운영했습니다. Claude·Codex와 외부 모델을 역할에 따라 활용하고 Git Worktree로 작업 공간을 나눴습니다. MCP 도구를 연동하고 PR과 WORKLOG로 변경 근거를 남겼습니다.
[역할 흐름도](../assets/diagrams/workflow.md)는 작성자의 설명을 바탕으로 새로 그렸습니다.

## 근거와 한계

2026-10-02 원본 파일 집계는 공동 개발을 포함한 7개 저장소의 WORKLOG 416개입니다. 모두 본인 단독 작성한 수가 아닙니다. 비공개 설정·PR·운영 기록의 원문은 포함하지 않습니다.
실제 수정·reject 기록과 QA 평가 효과의 공개 증빙은 아직 준비되지 않았습니다. 이중 관문 통과율·품질 개선률·비용 절감률을 주장하지 않습니다. 에이전트 제품 개발과 개발용 에이전트 운영 경험을 구분합니다.
