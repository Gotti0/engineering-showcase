# 금융 데이터 검증

## 문제와 역할

주식 퀀트 시스템에 선물 시계열 모듈을 추가하며 롤오버와 데이터 검사, 통계 지표의 단위를 검토했습니다. AI 코딩 에이전트와 함께 구현했고, 당시 결과와 한계를 작업 기록에 남겼습니다.

## 구현 구조

거래량 기반 롤오버와 OHLC 관계식 검사, 결함 행의 쓰기 시점 격리, DSR 입력의 연환산·기간당 단위 정렬을 다뤘습니다. 텍스트 분석 프로젝트에서는 경제 유튜브 자막을 분석해 종목과 연결했습니다. DART 재무제표 수집은 자막 감성 분석과 별도 경로입니다.
구조도·개념 ERD(assets/diagrams/financial-data-validation.md)는 공개 설명용이며 원본 운영 스키마가 아닙니다.

## 근거와 한계

공개 텍스트 분석 프로젝트는 코드 참조용입니다. 다른 시스템의 원본은 이 저장소에 포함하지 않습니다.
2026년 9월의 개발기 기록에는 관계식 위반 25품목·171행 격리, 재실행 이동 0행, 선물 테스트 82건 통과가 있습니다. 이는 비공개 과거 기록에 대한 작성자 설명이며 공개 독립 재검증 결과가 아닙니다.
이번 예제는 합성 OHLC 행의 검사·격리 재실행을 재현합니다. 롤오버·DSR 전체 엔진이나 전략 알파를 재현하지 않습니다.
