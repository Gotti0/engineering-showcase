## 배경

공개 showcase에 채용용 GitHub Pages가 필요했다. 실패 모드는 첫 화면 한 줄 포지셔닝 부재였다.

## 문제

마크다운만으로는 직무별 읽기 경로를 3분 안에 고르기 어렵고, 문서 테마(MkDocs)는 채용용 첫인상에 불리하다. 무프레임워크 HTML 생성은 페르소나 확장 비용이 커진다.

## 결정과 근거

Astro SSG(`site/`)로 루트 `cases/`·`audiences/`·`evidence/`·`examples/`를 빌드 시 읽어 `/for/<slug>` 라우트를 만든다. content collection 복제 대신 파일 시스템 로더로 공개 경계를 유지한다. MkDocs와 순수 HTML 생성 스크립트는 버렸다.

## 검증

2026-11-10 로컬 `npm run build`로 정적 페이지 13개가 생성됐고, 히어로 문장과 `/engineering-showcase/for/*` 링크가 `dist/index.html`에 포함됨을 확인했다. Pages 라이브 URL 확인은 워크플로 배포 후다.

## 미해결

GitHub Pages 소스(Actions) 설정과 homepage URL 반영은 원격 배포 후에 확인한다. 비주얼 톤은 1안이며 별도 디자인 패스는 없다.
