## 배경

여러 직무에 개발 사례를 전달할 공개 자료가 필요했다.

## 문제

원본 저장소 이력과 입력 자료를 일괄 복사하면 공개 범위와 기여 설명을 통제하기 어렵다. 작은 예제의 통과를 원본 시스템 전체 검증으로 혼동할 수 있다.

## 결정과 근거

저장소 하나에 사례와 직무별 안내를 두고, 기존 공개 프로젝트는 링크했다. 비공개 원본과 이력은 복사하지 않고 합성 입력의 별도 예제를 작성했다. 과거 검증 기록 설명과 이번 예제 실행을 근거 목록에서 구분했다.

## 검증

2026-10-02 Python 3.12에서 합성 예제 테스트 6개가 통과했다. 격리 1행·재실행 0행·예약 성공 1회를 확인했고, 공개 대상 17개 파일의 상대 링크와 개인 필드 부재를 점검했다. 이는 원본 운영 시스템의 검증 결과가 아니다.

## 미해결

비공개 과거 기록의 공개 독립 재현과 실제 QA reject 기록은 포함하지 않았다. 예제는 원본 시스템 전체 검증을 대신하지 않는다.
