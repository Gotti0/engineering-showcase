## 배경

공개 랜딩을 Astro로 다시 짠 슬라이드 덱으로 배포한 뒤, 사용자는 기존 `이현우_포트폴리오_슬라이드.html`을 그대로 재현하라고 요청했다.

## 문제

Astro 내러티브·CSS 재구성본은 원본 슬라이드의 레이아웃·톤·장표 구성을 복제하지 못한다. 링크 제거용 재작성은 유지 비용만 키웠다.

## 결정과 근거

`src/pages/index.astro`를 제거하고 원본 HTML을 `site/public/index.html`로 복사했다. `my_picture.jpg`·`paperclip_agents_tree.png`를 함께 둔다. Astro `base` 아래에서도 상대 경로 자산이 동작한다. `/p`·cases·evidence 라우트는 유지하되 랜딩에서는 안내하지 않는다.

## 검증

2026-11-10 `npm run build` 후 `dist/index.html` 크기 46852바이트(원본과 동일), 프로필·paperclip 이미지 존재, 루트 `<a` 앵커 0건.

## 미해결

원본 HTML의 퀀트 포지셔닝·프로젝트 서술과 백엔드 채용 메시지 정합은 손보지 않았다. Pages 배포는 별도 푸시 후 확인한다.
